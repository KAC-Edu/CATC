# KAC 공통 디자인 토큰 적용 — 배포 안내

## 무엇을 했나
8개 플랫폼이 **하나의 시각 언어**를 공유하도록 공통 토큰 파일(`kac-tokens.css`)을
만들고, 각 플랫폼 HTML `<head>`에 `<link>` 한 줄만 추가했습니다.
(GitHub 직접 푸시는 권한이 없어, 파일로 전달합니다.)

## 적용된 변경 (안전 · 표면 정돈만)
- **컬러 토큰**: 운영=블루 / 지원=그린 / 진행=인디고 + 의미색(위험·경고·성공·정보)
- **라운드**: 8 / 12 / 20 / 알약 4단계
- **그림자**: sm / md / lg 3단계
- **폼 포커스 링**: 전 플랫폼 블루 링으로 통일
- **스크롤바**: 데스크톱에서 얇고 중립적으로 통일
- **텍스트 선택 영역**: 브랜드 블루
- admin 전용: 모드탭 '무지개' 제거, 위험버튼(Reset) 1개만 빨강, 배경음 맥동 정지

## 되돌리기
각 HTML에서 `kac-tokens.css` 링크 한 줄만 지우면 원상복구.
admin.css는 맨 끝 "KAC 공통 디자인 토큰 v1" 블록만 지우면 됩니다.
